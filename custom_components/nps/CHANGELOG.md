# 更新说明

## 1.1.0（2026-10-22）

### 新增

- **隧道类传感器新增明细属性**：`隧道总数`、`TCP 隧道`、`UDP 隧道`、`SOCKS5 隧道`、`HTTP 代理隧道`、`秘密隧道`、`P2P 隧道`、`文件隧道` 的状态属性里新增 `tunnels`，列出该类型下每条隧道的 ID、备注、端口、内网目标、所属客户端与在线状态、运行/启用状态、进出流量（最多 50 条，`truncated` 标记截断；不写入 recorder）。

### 改进

- **面板增删自动同步实体**：面板里新建/删除隧道、客户端后，对应 `switch` 实体会自动创建或移除，**不再需要重载集成**；修改备注/端口/目标时属性与显示名就地更新。
- **删除更彻底**：移除实体的同时清理实体注册表条目，并自动清理此前版本残留的「不可用 / 还原」实体。
- 适配新版 `device_registry` API（`async_get_device_by_identifier`），消除 `async_get_device` 弃用警告（原定 2027.8 移除）。

### 修复

- 计数类传感器不再显示为 `0.0`，改为整数。
- 修复「所有实体」传感器在部分版本下添加失败（`TypeError: missing config_entry_id`）。
- 修复 `switch` 平台初始化时变量名写错导致整个平台加载失败、所有开关实体消失的问题。

## 1.0.0（2026-10-22）

### 新增

- **可视化管理面板**：隧道 / 客户端 / 域名映射三个选项卡，支持搜索、类型筛选、新建、编辑、复制、启停、删除。
- **设备页悬浮窗**：点设备「访问」不再跳转整页，改为弹可拖动、可缩放的 iframe 悬浮窗（`Ctrl`/中键仍开新标签）。
- **面板访问密钥**：`md5(集成盐 | 整点序号 | 主机地址 | 条目id)`，整点轮换、旧密钥宽限 1 小时；可用 `?key=` 短链接直接打开面板。
- **面板访问密钥传感器**：状态 = 剩余分钟数，属性含密钥、剩余时长、访问地址。
- **管理面板访问开关**：一键禁用/启用面板访问（禁用后链接失效、接口拒绝）。
- **轮询间隔可配**：选项流设置 5~3600 秒（默认 30 秒），保存后自动重载。

### 改进

- 传感器全部中文化（19 个），并用固定 `object_id` 保证升级后 `entity_id` 不变。
- 面板接口支持 websocket 与 HTTP 双通道，独立页面与侧边栏同源复用。
